## 👩🏻‍💻 About Me

> **좋은 사용자 경험은 안정적인 데이터 흐름과 비즈니스 로직이 뒷받침될 때 완성된다고 믿습니다.**

실용음악을 전공하던 중 라이브 코딩 음악 프로그램 **Sonic Pi**에서 코드가 실시간으로 소리가 되는 경험을 하고 개발을 시작했습니다.
웹 퍼블리싱 교육과 **UI/UX 인턴십**으로 화면과 사용자 흐름을 익혔고, **AI 기반 풀스택 엔지니어 과정**에서 서버·DB·API 연동까지 웹 서비스 전체를 다루고 있습니다.

- 🎨 **UI/UX 실무 경험** — Mets HIT 인턴십, 삼성 One UI 8.x Watch Principle 문서 마이그레이션 참여
- 🧩 **풀스택 개발** — React · Next.js 프론트엔드부터 FastAPI · Spring Boot 백엔드, DB 설계까지
- 🤖 **AI 서비스 구현** — Whisper, LangChain, LangGraph, RAG를 활용한 실제 동작하는 AI 기능
- 🏆 **팀 리딩** — 세 번의 팀 프로젝트 중 두 번 팀장, 기업 제안 프로젝트 **최우수상** 수상
